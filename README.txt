# Gauteng EMS Help Desk — Runaway Login

Responsive version using the supplied Gauteng EMS logo and system name.

The layout is optimized for desktop/laptop browser heights and mobile screens so the login card and footer are not cut off.

Run locally:
1. Open Command Prompt.
2. cd /d D:\DOWNLOADS\gauteng_ems_help_desk_runaway_login
3. py -m http.server 5500
4. Open http://localhost:5500
